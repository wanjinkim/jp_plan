# JAPAN ATLAS · 2026 · 연구 재구성 정적 배포본

- **GitHub Pages**: 파일과 assets 폴더 전체를 저장소 루트에 올리고 Settings → Pages → Deploy from a branch → main / (root).
- 비밀번호·세션·서버·항공권/숙소 검색 폼 없음.
- 메인 섹션 01 직접 추천 코스, 02 6개 도시, 03 사진 모음.
- `?page=routes&city=hiroshima` 등 6개 도시마다 기존 원본 수정 일정과 별도인 신규 3일 코스를 표시합니다.
- `?page=flights`: 운임 가격 비교 *검증 상태* 화면. 동일 날짜 실제 운임 데이터가 불충분하므로 가짜 최저가 TOP 5를 만들지 않았습니다.
- **갱신** 버튼은 게시된 assets/recommended.json 재불러오기이며 AI 실시간 검색을 실행하지 않습니다. 개발자가 자료조사 후 JSON을 커밋하면 모든 방문자에게 최신 데이터가 반영됩니다.
- `recommended.json`의 대부분 구간은 일정 배분값입니다. 실제 교통편 시간표·도보 15분 조건의 모든 구간 검증을 주장하지 않습니다.
- Commons 이미지를 외부 연결합니다. 이미지를 자체 파일로 다운로드한 것이 아니고, 실제 촬영 장소와 음식 참고사진은 구분합니다. 맞는 사진이 없으면 다른 장소 사진을 대신 쓰지 않습니다.
- 모든 외부 링크는 엄격히 허용한 도메인만 사용하며 이동 전 확인창 표시.
- 난수 이름의 공개 GitHub Pages는 **비공개 사이트가 아닙니다**.

Research date 2026-11-10. 주요 공식 근거는 추천 코스의 출처 목록을 참조하세요.
