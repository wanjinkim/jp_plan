# JAPAN ATLAS · 12개 도시 · 4인 예산 비교

GitHub Pages 정적 사이트입니다. `index.html`, `assets/` 폴더, `.nojekyll`을 저장소 최상위에 올리고 Settings → Pages → main / (root)를 선택하세요.

## 최종 카테고리

1. 기존 추천 도시 6곳: 히로시마, 시즈오카, 삿포로, 나고야, 오키나와, 센다이. **09:00 현지 공항 도착 가정**.
2. 신규 여행 후보 6곳: 후쿠오카, 오사카, 도쿄, 마쓰야마, 다카마쓰, 구마모토. **오전 11시 이전 도착 정기편 사례를 참고**, 11/27 좌석·가격 확정 아님.
3. 사진 모음: Wikimedia Commons 실사진 URL과 구글 이미지 검색 연결.

## 4명 숙박 비교 (만원)

`assets/budgets.json`에서 항공·식비·교통·관광·예비비는 **1인 2박3일 기준 예산 가정**, twin은 **2인실 1개·1박 비용**, quad는 **4인실 1개·1박 비용**입니다.

- 2명씩 2객실: 4 × (항공+식비+교통+관광+예비비) + 2객실 × 2박 × twin
- 4명 함께 1객실: 4 × (항공+식비+교통+관광+예비비) + 1객실 × 2박 × quad

모든 값은 **예약가 아닌 계획 가정**입니다. 11월 27~29일 네이버 항공권 실시간 왕복 운임과 최근 3개월 금~일 표본은 충분히 확보하지 못했습니다. 확정 운임이나 검색 결과처럼 표현하지 않습니다. 세금·수하물·추가 침구·현지 객실세는 개인별 확인 필요. 쇼핑 제외.

숙박 비교에 4인실을 따로 표시한 이유는 객실 수용 인원과 요금이 다른 상품이기 때문입니다. 4인실 예약이 가능한지 객실 상세 조건을 확인하세요.

## 실행 가능성

일정은 자연과 온천을 필수로 포함했고 승용차·택시 이동을 제외한 대중교통 동선 제안입니다. **모든 환승 이동 도보 15분과 교통편 분 단위 실측을 완료한 것은 아닙니다**. 관광·트레킹 자체의 걷기는 15분 제한과 별도로 다룹니다. 도시 상세 페이지에서 구글지도 대중교통으로 이동 전에 확인하세요.

## 외부 이미지 및 링크

사진은 링크로 사용하고, 다운로드해 포함한 파일이 아닙니다. 원본 이미지가 사라지면 개별 카드는 이미지 검색으로 대체됩니다. 사이트의 외부 링크는 Google Maps / Google Images / Wikimedia Commons / 출처 공식 도메인만 승인 리스트를 통해 안내하고 이동 전 확인창을 표시합니다. 링크를 아는 사람은 누구나 접속할 수 있는 공개 사이트입니다.
